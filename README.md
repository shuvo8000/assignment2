# 🎙️ TechWave — Podcast Landing Page

A modern and responsive podcast landing page designed for **TechWave**, a fictional technology podcast focused on tech insights, productivity, career growth, and personal development.

The website features a dark futuristic interface with vibrant gradient colors, podcast episodes, host information, statistics, and social media integrations.
